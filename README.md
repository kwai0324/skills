# 个人技能仓库

保存可复用的助手技能及其必要规则和工具。

## 分步出题助手

[查看技能说明](question-bank-wizard/SKILL.md)

根据题库生成工具的命题规范，每轮询问1个步骤，逐步确认课程、培养层次、范围、题型数量、卷别和交付格式，生成题目、答案及解析。

支持11种题型、标准300题、自定义题量及A、B卷，并提供题量、答案配额、字段、文本兼容和重复题校验。

将question-bank-wizard目录放入本机的个人技能目录后，可以输入「使用分步出题助手，按程序规范带我逐步出题」。

校验和办公文件导出需要题库生成工具的源码及对应Python依赖，兼容原根目录布局和新版app布局。程序目录、执行方法与模板要求见[本地交付说明](question-bank-wizard/references/delivery.md)。

本地结构校验不替代教学内容审核，正式使用前仍须核对知识结论与来源。
